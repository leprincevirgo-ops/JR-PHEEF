## Behavior and compatibility

- The same category label should be used in the UI, API, listings and analytics.
- Category search and listing creation must validate against this list.
- Historical values "Data & Analytics" and "New & Noteworthy" are accepted as aliases so older listings remain discoverable; new listings use the official labels "Data&Analytics" and "New&Noteworthy".
- A category tile is an entry point, not proof that every service within that category is live.
- Regulated or high-risk activity must remain restricted until the relevant workflow, moderation and compliance review are complete.

## Readiness rule

Do not call a feature production-ready until it has been tested end-to-end against the actual database and deployment. Never represent a planned payment, lending, investment, delivery or external integration as live without provider integration and verification.
