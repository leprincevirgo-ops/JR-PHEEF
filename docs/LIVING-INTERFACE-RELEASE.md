# JR PHEEF — Living Interface Release

This release adds a progressive visual layer to the existing foundation rather than replacing working routes or account flow.

## Brand system
- Space Blue `#07152E`, Deep Navy `#0B1D3A`
- Electric Violet `#813BFF`, Living Cyan `#00D9E8`
- White `#FFFFFF`, Titanium Silver `#A7B5CC`
- Semantic colours: success `#20C997`, warning `#FFB547`, danger `#FF647C`

## Experience modes
- Living: immersive connected-universe default.
- Focus: quieter presentation for concentrated work.
- Professional: restrained business/workspace presentation.

The selected mode is stored locally on the device. It does not change permissions, data, pricing, or account status.

## Navigation and accessibility
- Retains HOME, WORLDS, JR and COMMAND CENTER as the four primary destinations.
- Adds accessible back and return-to-top controls.
- Mobile navigation respects device safe-area insets.
- Keyboard focus indicators and reduced-motion preferences are respected.

## Product boundaries retained
This is a visual/navigation enhancement. It does not claim to connect a production general-purpose AI model, payments, regulated finance, live delivery dispatch, or unverified third-party integrations. Existing authentication and database security remain the source of truth. Sensitive actions still require authorization.
