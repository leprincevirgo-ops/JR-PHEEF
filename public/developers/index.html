Send an event

Example request from your server (replace the environment variable with the one-time token):

curl -X POST https://jr-pheef-marketplace.onrender.com/api/inbound/jr/events \
  -H "Authorization: Bearer $JR_PARTNER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "event_type": "inventory_update",
    "title": "Stock count updated",
    "summary": "Product ABC has 12 units recorded.",
    "external_event_id": "stock-count-001",
    "event_data": {
      "category": "stock",
      "quantity": 12,
      "unit": "items"
    }
  }'

Accepted event types: status_update, task_update, inventory_update, delivery_update, message_received, calendar_update, other. Reuse the same external event ID when retrying; duplicate events are safely acknowledged.
